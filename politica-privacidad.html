2. Finalidad del Tratamiento

Los datos personales facilitados por el usuario a través del correo electrónico o del enlace de WhatsApp disponible en la web serán utilizados únicamente para:

3. Base Legal del Tratamiento

La base legal para el tratamiento de los datos es el consentimiento expreso del usuario al remitir voluntariamente una comunicación, conforme al artículo 6.1.a del RGPD.

En el caso de propuestas de colaboración profesional o incorporación laboral, la base legal podría ser también la aplicación de medidas precontractuales a petición del interesado (art. 6.1.b del RGPD).

4. Conservación de los Datos

Los datos personales proporcionados se conservarán durante el tiempo estrictamente necesario para responder a la consulta formulada o mientras se mantenga la relación profesional o comercial, y en todo caso durante los plazos legalmente exigibles. Una vez finalizada la finalidad, los datos serán suprimidos o, en su caso, anonimizados.

5. Destinatarios y Cesiones

No se cederán datos personales a terceros salvo obligación legal. No se realizan transferencias internacionales de datos a países fuera del Espacio Económico Europeo.

Los servicios de correo electrónico y mensajería utilizados (por ejemplo, Gmail y WhatsApp) actúan como encargados del tratamiento y disponen de sus propias políticas de privacidad y garantías de cumplimiento del RGPD.

6. Alojamiento web y transferencia internacional de datos

Este sitio web está alojado en la plataforma GitHub Pages, un servicio proporcionado por GitHub Inc. (EE. UU.). Al acceder a este sitio, GitHub procesa automáticamente datos técnicos como la dirección IP del visitante, la fecha y hora de acceso, y el navegador utilizado, con la única finalidad de garantizar la seguridad y el correcto funcionamiento del servicio.

Dado que GitHub tiene su sede en Estados Unidos, se produce una transferencia internacional de datos a un tercer país. GitHub cumple con el RGPD y ofrece garantías adecuadas para dicha transferencia, amparándose en las Cláusulas Contractuales Tipo aprobadas por la Comisión Europea y en su certificación bajo el Marco de Privacidad de Datos UE-EE. UU.

Para más información, puede consultar la Declaración de Privacidad de GitHub en su sitio web oficial.

7. Derechos del Usuario

El usuario puede ejercitar en cualquier momento los siguientes derechos:

  • Acceso: conocer qué datos personales se están tratando.
  • Rectificación: solicitar la corrección de datos inexactos.
  • Supresión: solicitar la eliminación de sus datos (derecho al olvido).
  • Limitación: solicitar la limitación del tratamiento.
  • Oposición: oponerse al tratamiento de sus datos.
  • Portabilidad: recibir sus datos en un formato estructurado y de uso común.

Para ejercer cualquiera de estos derechos, basta con enviar un correo electrónico indicando la solicitud y adjuntando un documento acreditativo de identidad a jaime.terciado@gmail.com.

8. Derecho a Reclamar ante la Autoridad de Control

Si el usuario considera que el tratamiento de sus datos personales no se ajusta a la normativa vigente, o no obtiene satisfacción en el ejercicio de sus derechos, tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD), autoridad de control competente en España.

Puede consultar los procedimientos disponibles y presentar la reclamación a través del sitio web oficial: www.aepd.es.

9. Medidas de Seguridad

El responsable del tratamiento aplica medidas técnicas y organizativas apropiadas para garantizar un nivel de seguridad adecuado al riesgo, conforme al artículo 32 del RGPD, evitando la pérdida, mal uso, alteración, acceso no autorizado o robo de los datos personales facilitados.

10. Modificaciones de la Política de Privacidad

El responsable se reserva el derecho a modificar la presente política para adaptarla a novedades legislativas o jurisprudenciales. En tal caso, se anunciará en esta página con la fecha de la última actualización.
